# Email Scheduler

An automated email scheduling application designed to help users compose, schedule, and send emails at specified dates and times. 

## Features

- **Scheduled Delivery:** Queue and send emails automatically at your preferred date and time.
- **User-Friendly Interface:** Clean and intuitive layout for managing your scheduled messages.
- **Reliable Backend:** Built to handle background tasks and ensure messages are sent on time.
- **Status Tracking:** Monitor whether your emails are pending, sent, or failed.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js / Express
- **Database:** MongoDB / PostgreSQL
